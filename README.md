## ez_utils

A high-performance utility library designed to eliminate boilerplate code in Go applications. Built for production-scale services and CLI tools.

### Included Packages:
* **`colors`**: Simplified terminal text coloring using standard Hex codes (`#000000`) with dedicated `ColorPrint` and `ColorPrintln` engines.
* **`scanner`**: A clean, 120-line robust CLI input scanner featuring native EOF handling, string sanitization, and type-safe parsing (`Scanln`, `NextInt`, `NextBool`, etc.).

### Installation
```bash
go get github.com/cribest7890/ez_utils
```
